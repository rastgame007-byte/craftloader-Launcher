# 🧩 CraftLoader 2.2 — моды, сборки и запуск Minecraft

Комбайн-лаунчер для Windows: моды с Modrinth и CurseForge, готовые
сборки в один клик, СВОИ сборки и настоящий запуск игры без лаунчера.

## Что нового в 2.2

- 🎮 **Запуск Minecraft прямо из приложения** — CraftLoader сам скачает
  версию игры, ассеты и библиотеки с серверов Mojang и запустит игру с
  твоим ником (оффлайн, без аккаунта и пароля). Vanilla, Fabric и Quilt.
  Forge/NeoForge-модпаки — по-прежнему через Prism Launcher
- 👤 **Ник и память** — оффлайн-ник (UUID генерируется сам), выбор
  выделенной памяти 2–16 ГБ
- ☕ **Java сама** — приложение найдёт установленную Java, а если её нет
  или версия не подходит — скачает официальный рантайм Mojang
  (нужная версия под выбранную версию игры)
- 🗂 **Свои сборки** — новый раздел «Мои сборки»: жми «＋» у любой версии
  мода, чтобы добавить его в свою сборку. Потом «Установить и
  запустить» — моды скачаются в отдельную папку и игра стартует с ними
- 🎯 **Выбор сборки для запуска** — на странице «Игра» все твои сборки
  карточками: у каждой своя кнопка «Запустить». Клик — и игра стартует
  именно с этой сборкой. У установленных сборок тоже кнопки запуска
- 📁 **Собрать из папки mods** — одна кнопка превращает уже скачанные
  моды в сборку
- 🚀 **Запуск установленной сборки** — на странице «Игра» у сборок
  CraftLoader появилась кнопка ▶ (если версия и загрузчик известны)

## Запуск игры — как это работает

1. Страница «Игра» → выбери ник, версию Minecraft, загрузчик
   (vanilla / fabric / quilt) и память
2. «Запустить» — при первом запуске скачается ~400 МБ файлов игры,
   дальше запуск мгновенный
3. Игра стартует в отдельном окне с твоим ником. Серверы с
  `online-mode=true` не пустят (оффлайн-ник), одиночка и обычные
  серверы — работают
4. Если что-то пошло не так — смотри `craftloader-launch.log` в папке игры

## Как запустить

1. Запусти `CraftLoader.exe`.
2. SmartScreen может предупредить о неизвестном издателе (нормально для
   самособранных программ): **«Подробнее» → «Выполнить в любом случае»**.
3. Приложение само найдёт папку `mods` (стандартный `.minecraft` или Prism),
   а если её нет — создаст свою и всё сразу будет качаться туда. Папку можно
   поменять в «Настройках», а на странице «Моды» показан текущий путь.

## Требования

- Windows 10/11 x64, интернет
- Java не обязательна: приложение скачает рантайм Mojang само
- Файлы игры лежат в `%APPDATA%\craftloader\runtime`, свои сборки — в
  `%APPDATA%\craftloader\instances`

## Функции из прошлых версий

- 🔍 **Моды** — сотни тысяч с Modrinth: поиск, фильтры по загрузчику,
  версии и категориям, пагинация
- 📦 **Готовые сборки** — модпаки с Modrinth (.mrpack) и CurseForge:
  установка в отдельную папку, в .minecraft или скачивание архива
- 🟠 **CurseForge по ссылке** — любой мод или сборка по ссылке, слагу
  или ID
- 🔄 **Обновления модов** — отслеживание и «обновить всё»
- ⭐ **Избранное**, ⚡ **мини-сборка «Минимальная оптимизация»** (8
  перфоманс-модов)

## Сборка из исходников

Нужен Go 1.23+. Интерфейс лежит в `ui/index.html` и вшивается в exe
через `go:embed`, иконка — в `rsrc_windows_amd64.syso`.

```
# Windows exe (кросс-компиляция с любой ОС)
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w -H windowsgui" -o CraftLoader.exe .

# проверить на Linux/macOS без окна: сервер + UI в браузере
CL_NOBROWSER=1 go run .
```

GitHub Actions уже настроен (`.github/workflows/build.yml`): пушнишь тег
`v2.3` — соберёт exe и приложит к Release автоматически.

## Структура

| Файл | Что делает |
|---|---|
| `main.go` | API-сервер, поиск/моды/конфиг, готовые модпаки |
| `launcher.go` | движок запуска игры (Mojang, fabric/quilt, Java) |
| `packs.go` | свои сборки |
| `ui/index.html` | весь интерфейс |
| `win.go`, `nix.go`, `hideproc_*.go` | окно и платформенные мелочи |
