# UI-тесты (jsdom)

Гоняются против живого сервера:

```
CL_NOBROWSER=1 go run . &          # запустит сервер, порт в логе
npm install jsdom
node tests/uitest-full.js 127.0.0.1:PORT     # полный сценарий
node tests/uitest-launch.js 127.0.0.1:PORT   # запуск сборки
node tests/uitest-download.js 127.0.0.1:PORT # скачивание мода
```

Тесты кликают по реальному UI: модалка мода, скачивание, установка
сборок, страница «Игра». Ожидают папку модов и тестовую сборку
«Моя сборка» (создаётся через API).
